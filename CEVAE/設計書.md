## 0. この実験で「主張したいこと」

> **観測できる X は潜在交絡因子 Z の「ノイズ込みの代理（proxy）」にすぎない。**
> X で調整するふつうの手法（S/T/X-learner, TARNet）は、X≠Z のぶんだけ
> **残差交絡（residual confounding）が残りバイアスする。**
> CEVAE は複数の proxy から Z を復元しようとするので、ある条件下でこのバイアスを減らせる。

重要な姿勢：**「CEVAE は万能」とは主張しない。**
文献（Rissanen & Marttinen, NeurIPS 2021）では CEVAE が Z を安定に復元できずベースラインに負ける報告もある。
そこで本実験は **「CEVAE が勝つスイートスポット」と「勝てない領域」の両方を示す**。これが学術的に最も誠実で、発表でも刺されない。

```
proxy が少ない/ノイズ過多 → CEVAE も Z を復元できず優位性は消える
proxy が多く情報豊富       → ふつうの手法も X≈Z で調整でき、差が消える
              ↑その中間↑   → CEVAE が最も光る  ← ここを主役にする
```

## 1. 因果構造（DGP のDAG）

```
          Z  (潜在交絡。モデルには絶対に渡さない)
        / | \
       /  |  \
      ↓   ↓   ↓
   X(複数) T → Y
```

- Z → X : X は Z の **proxy**（原因ではない。ここが本質）
- Z → T : 交絡（処置選択が Z に依存）
- Z → Y : 交絡（結果が Z に依存）
- T → Y : 推定したい因果効果

**観測できるのは X, T, Y のみ。** T も Y も **Z のみに依存**させる（X に直接依存させない）。
こうしないと X が proxy でなく真の交絡因子になってしまい、CEVAE の優位が消える。

## 2. 人工データ生成（DGP）

### 2.1 生成式（**Z は2次元ベクトル**）

`Z = (z1, z2)` の2次元潜在交絡。`a_j`・`θ`・`β` は2次元ベクトル、`Z` との内積をとる。

```
潜在交絡  Z_i      ~ N(0, I_2)                                # 2次元。観測しない
代理変数  X_ij     = a_j · Z_i + e_ij ,  e_ij ~ N(0, σx²)     # a_j は2次元ベクトル, j=1..d
処置      T_i      ~ Bernoulli( sigmoid( γ · (z1+z2)/√2 ) )   # γ = 交絡強度ノブ（スカラー）
結果      Y_i(t)   = μ0 + θ·Z_i + t*(α + β·Z_i) + η_i ,  η_i ~ N(0, σy²)
観測結果  Y_i      = Y_i(T_i)
```
- `a_j`：proxy ごとの2次元ローディング（各窓が z1,z2 をどう混ぜて映すか）。乱数で固定。
- 2次元化の狙い：窓 d=10 あっても線形平均で Z を復元しきれず、CEVAE の構造仮定（低次元ボトルネック）が活きる。

### 2.2 真の ITE / ATE（人工データなので解析的に出せる）

```
真の ITE_i = Y_i(1) - Y_i(0) = α + β·Z_i        # Z に対して異質（heterogeneous）
真の ATE   = E[α + β·Z] = α                       # Z の平均が0なので
```

- `β ≠ 0` にすることで ITE がサンプルごとに異なり、CATE / PEHE が意味を持つ。
- `θ`（Z→Y）と `γ`（Z→T）の両方が非ゼロのとき交絡が発生。

> ★ CEVAE の優位の出どころ（設計上の前提）：観測 X に含まれる Z の情報量は決まっており、
> CEVAE も X 以上の情報は引き出せない。CEVAE の強みは「Y の原因は低次元 Z だけ」という
> 正しい構造を仮定するため**過学習しにくく推定が安定する**点と、proxy 調整の残差交絡を
> 減らせる点。一方 proxy 調整ベースライン（S/T/X-learner）には**N→∞でも消えない交絡バイアス**
> が残る。だから N を大きくしても γ-sweep の差は出る。

### 2.3 デフォルトのパラメータ（確定・基準設定）

| 記号 | 意味 | 既定値 |
|---|---|---|
| **Z次元** | 潜在交絡の次元 | **2** |
| **N** | サンプル数 | **20000**（train/test = 0.7/0.3, stratify=W） |
| **d** | proxy の本数 | **10** |
| a_j | proxy ローディング | 2次元, 乱数で固定 |
| σx | proxy ノイズ | 1.0（σx-sweep で振る） |
| γ | Z→T 交絡強度 | 1.5（γ-sweep で振る） |
| θ | Z→Y 交絡強度 | (2.0, 2.0) |
| α | ITE 平均（=ATE） | 1.0 |
| β | ITE の異質性 | (1.0, 1.0) |
| μ0, σy | 結果のベース・ノイズ | 0, 0.5 |
| seeds | 平均±SD用の試行数 | 20 |

> 注：σx=0 にすると X が Z の線形射影（ほぼ完全観測）になり手法差が縮む。σx↑で proxy 劣化。

## 3. 比較モデル（4段階のスペクトラム + Oracle）

差が一目で伝わるよう、**わざと「悪い→良い→理想」の階段**を作る。

| # | モデル | 使う情報 | 期待される位置 | 実装 |
|---|---|---|---|---|
| 0 | **Naive**（差の平均 / Y~T のみ） | なし | 全交絡で最悪。交絡の存在証明 | 数行 |
| 1 | **S-learner** | X | 残差交絡で偏る | 去年の卒論コード流用 |
| 2 | **T-learner** | X | 同上 | 同上 |
| 3 | **X-learner** | X | 同上（やや改善） | 同上 |
| 4 | **TARNet**（任意） | X | ニューラル版の同クラス | 小さめ PyTorch |
| 5 | **CEVAE** ★ | X→Z 復元 | スイートスポットで改善 | 新規実装 |
| 6 | **Oracle** | 真の Z | 達成不能な上限 | T-learner に Z を渡すだけ |

- base learner は去年と揃える（RandomForest / XGBoost）。
- **Oracle を必ず入れる。**「CEVAE が Oracle との差をどれだけ埋めたか」が改善幅の最強の証拠になる。
- TARNet は「ニューラルでも proxy 調整では限界がある」を示す比較用。時間がなければ省略可。

## 4. CEVAE 本体の構成（フルスクラッチ実装の設計）

### 4.1 推論モデル（Encoder, q）
```
q(t | x)         : MLP(x) → Bernoulli logit                     # 補助NW
q(y | x, t)      : 2ヘッド MLP（t=0/t=1 で別ヘッド）→ 平均        # 補助NW
q(z | x, t, y)   : 共有表現 h = MLP(x);  t で分岐し [h, y] → (μ_z, logσ²_z)
                   → z ~ N(μ_z, σ²_z)（reparameterization）
```

### 4.2 生成モデル（Decoder, p）
```
p(z)      = N(0, I)
p(x | z)  : MLP(z) → 連続 proxy なので Gaussian（平均を学習、分散は固定）
p(t | z)  : MLP(z) → Bernoulli logit
p(y | t,z): 2ヘッド MLP（t=0/t=1）→ 平均（分散固定 ⇒ 実質 MSE）
```

### 4.3 損失 = −ELBO + 補助損失
```
L = 再構成_x (Gaussian NLL ≒ MSE)
  + 再構成_t (BCE)
  + 再構成_y (MSE)
  + KL( q(z|x,t,y) || N(0,I) )          # ← β_kl で重み付け（KLアニーリング）
  + 補助: BCE(q(t|x), t) + MSE(q(y|x,t), y)
```
- **安定化トリック**：KL項を学習初期は0から徐々に1へ上げる（KL annealing）。posterior collapse 対策。

### 4.4 テスト時の ITE 推定（x だけが既知）
```
1. t̂ = q(t|x)                         # 補助NWで処置を予測
2. ŷ = q(y|x, t̂)                       # 補助NWで結果を予測
3. z ~ q(z|x, t̂, ŷ)（μ_z を使う or 複数サンプル平均）
4. y0 = p(y|t=0, z),  y1 = p(y|t=1, z)
5. ITE_pred = y1 - y0
```

## 5. 評価指標

人工データなので真の ITE が分かる。test セットで評価。

```
PEHE   = (1/N) Σ ( ITE_pred_i − ITE_true_i )²        # Precision in Estimation of Heterogeneous Effect
√PEHE  = sqrt(PEHE)                                   # ← 因果推論の標準報告値
MAE    = (1/N) Σ | ITE_pred_i − ITE_true_i |
ε_ATE  = | mean(ITE_pred) − mean(ITE_true) |          # ATE 誤差
```
- 標準ペアは **√PEHE と ε_ATE**。MSE/MAE も併記。
- **必ず複数シード（例 20回）で平均 ± 標準偏差**を出す。CEVAE は分散が大きいので 1回の結果で語ると再現性で刺される。図はエラーバー付き。

## 6. 実験（2つの sweep）

「sweep」＝他を固定して**ツマミ1個だけ**を段階的に変え、誤差の動く傾向を折れ線で見ること。
**メインは γ-sweep。σx-sweep は時間があれば。**（N-sweep は N=20000固定で進めるため今回はやらない）

### Sweep A（メイン）：交絡強度 γ を振る（「交絡が強いほど誤差がどうなるか」）
- γ（Z→T）∈ {0, 0.5, 1.0, 2.0, 3.0} を振る。他は既定値。
- 期待：γ↑ で Naive と proxy系のバイアス↑。CEVAE と Oracle は相対的に頑健。
- この差は **N→∞ でも消えない交絡バイアス**なので N=20000 でもはっきり出る。
- 図：横軸 γ、縦軸 √PEHE、各モデルを折れ線（エラーバー付き）。

### Sweep B（任意）：proxy の質 σx を振る（「スイートスポット」の証明）
- σx（proxy ノイズ）∈ {0.5, 1.0, 2.0, 3.5} を振る。
- 期待：両端で差が縮み、中間で CEVAE が最も Oracle に近づく **谷型**の優位差。
- 図：横軸 σx、縦軸「CEVAE と best baseline の √PEHE 差」。

## 9. 発表ストーリー（スライドの流れ案）

1. 問題提起：未観測交絡があると因果推論は偏る（Naive の悲惨な √PEHE を見せる）
2. でも X で調整すれば良いのでは？ → X は Z の **proxy** にすぎない（残差交絡が残る）
3. CEVAE のアイデア：複数 proxy から Z を VAE で復元 → モデル図（理解した3章の内容）
4. 実験設定：人工データの DAG と DGP
5. 結果1：基準設定の √PEHE 階段（Naive > learner > CEVAE > Oracle）
6. 結果2：交絡が強いほど CEVAE の相対優位が出る（Sweep A）
7. 結果3：CEVAE が効くのは「proxy が中程度」のスイートスポット（Sweep B）← 正直な限界提示
8. 結果4：復元 z vs 真 Z で「本当に Z を捉えているか」
9. まとめ：CEVAE の強み（proxy denoising）と弱み（不安定・スイートスポット依存）→ 自分の研究の動機へ

## 10. リスク・注意点（実装前に握っておく）

- **CEVAE は学習が不安定**。シード複数 + KLアニーリング + 早期終了で対処。1シードの結果を信じない。
- **公平性**：全モデルが観測する covariate は X のみに統一。Z は Oracle 以外には絶対渡さない。ニューラル系（TARNet, CEVAE）は学習予算（epoch, 層幅）を揃える。
- **β（ITE異質性）が0だと** CATE が定数になり PEHE が ATE誤差とほぼ同義になる。必ず β≠0。
- **σx の選び方が勝敗を決める**。基準設定を「CEVAE がやや勝つ」中程度に置き、Sweep で両端を見せる。意図的に CEVAE 圧勝の設定だけ見せない（＝reviewer に刺される）。
- 去年のコードは notebook 散在 + コピー多数。**動く最小版だけ baselines.py に整理移植**する（全部は持ってこない）。

### ⚠️ DGPは別物なので作り替える（去年のは今回の主張に使えない）
去年の `simulate_cate_zero` / `assign_W_and_observe` の問題：
1. **交絡なし**：`W = binomial(1, 0.5)`（完全ランダム化＝RCT）。潜在交絡Zが存在しない。
2. **効果ゼロ・均質**：`mu1 = mu0.copy()` で `tau_true = 0`。PEHEがノイズしか測れない。
3. X は観測共変量であって proxy ではない（潜在Zが無い）。

→ ジェネレータを設計書 §2 のDGPに差し替える。最小の変更点：
```
+ 潜在 Z を生成（N(0,1)）。観測しない
  X を Z の proxy に：X = a*Z + ε        （去年は X が独立共変量だった）
  W ~ Bernoulli(sigmoid(γ*Z))            （去年は 0.5 固定 → 交絡を入れる）
  tau_true = α + β*Z                      （去年は 0 → 非ゼロ・異質に）
  Y(t) = μ0 + θ*Z + t*(α+β*Z) + η         （Y を Z に依存させる）
```
モデル学習・評価・可視化は去年の機械をほぼ流用、**変えるのは「データの作り方」だけ**。
